# THU-CST-JTDL-2024summer

Course assignments for Introduction to Deep Learning (Summer 2024), Department of Computer Science and Technology, Tsinghua University.

## Course Information

- **Course**: Introduction to Deep Learning (深度学习导论)
- **Semester**: Summer 2024
- **Department**: Department of Computer Science and Technology, Tsinghua University

## Requirements

### Deep Learning Frameworks
- [Jittor](https://github.com/Jittor/jittor) - Primary deep learning framework used in this course

### Dependencies
See individual assignment directories for specific requirements.

## Installation

```bash
# Install Jittor
pip install jittor

# For GPU support, follow the official guide at:
# https://github.com/Jittor/jittor#installation
```

## Usage

Navigate to each assignment directory for specific instructions:

```bash
cd PA1-DigitReconstruct  # or PA2-FewShotLearn or PA3-JNeRf
# See README in each directory for details
```
